# Third-party art, fonts and audio

Everything vendored under `Assets/_Project/Art/` and `Assets/_Project/Fonts/` is either
public domain or openly licensed. Nothing here requires a runtime attribution screen, but
the sources are recorded so the capstone defense can answer "where did the art come from".

## Art and audio — CC0 1.0 Universal (public domain)

Created and released by **Kenney** (https://kenney.nl). CC0 waives all copyright: usable
commercially or non-commercially, no permission needed, no attribution legally required.

Because `kenney.nl` was unreachable from the development machine, the packs were fetched
from two mirrors that redistribute them unchanged: OpenGameArt.org and the
`ETdoFresh/kenney.nl` GitHub mirror.

| Folder | Pack | Fetched from |
| --- | --- | --- |
| `Art/UI/Frames/`, `Art/UI/FramesDouble/` | Fantasy UI Borders | `opengameart.org/sites/default/files/kenney_fantasy-ui-borders.zip` |
| `Art/UI/Widgets/` | UI Pack (Grey / Default subset) | `opengameart.org/sites/default/files/kenney_ui-pack.zip` |
| `Art/UI/Rpg/` | UI Pack — RPG Expansion | `opengameart.org/sites/default/files/UIpack_RPG.zip` |
| `Art/Icons/` | Game Icons (White / 2x subset) | `opengameart.org/sites/default/files/Kenney_gameIcons.zip` |
| `Art/Sfx/` | Interface Sounds | `github.com/ETdoFresh/kenney.nl` → `kenney_interfacesounds/Audio` |

Only the subsets actually used were vendored — the full packs are several times larger.
Files in `Art/Sfx/` were renamed to their role (`click_001.ogg` → `ui_click.ogg`).

## Fonts — SIL Open Font License 1.1

Fetched from the `google/fonts` repository. Full license text sits beside each family as
`Cinzel-OFL.txt` and `Spectral-OFL.txt`; both must stay with the fonts.

| File | Family | Designer |
| --- | --- | --- |
| `Fonts/Cinzel-{Regular,Bold,Black}.ttf` | Cinzel | Natanael Gama |
| `Fonts/Spectral-{Regular,Medium,SemiBold,Bold}.ttf` | Spectral | Production Type |

Cinzel is the display face — Roman inscriptional capitals, which is the register the
1896 revolutionary-document look wants. Spectral is the body face, chosen over Alegreya
because it ships true static weights rather than a variable-only TTF.

Both families are taken as **static** weights rather than variable `[wght]` builds.
`google/fonts` now ships Cinzel variable-only, and baking a variable font into a TMP SDF
atlas takes the default axis instance with metrics that do not always match the named
weight. Cinzel therefore comes from its upstream repository, `NDISCOVER/Cinzel`, which
still publishes true statics under the same OFL licence.

## What is *not* third-party

The Katipunan identity — the eight-rayed sun-of-liberty sigil, the baybayin `ᜃ` / `KKK`
motif, the parchment palette, and every terrain and unit sprite composited for the board —
is generated by this project's own code (`Scripts/UI/Kit/Theme.cs`,
`Scripts/Gameplay/PlaceholderArt.cs`). The Kenney packs supply neutral frames, widgets and
icons that are recoloured into that palette; none of them are Filipino-specific.

## Music, splash and added sound effects

The music loops, stings and the coin and hit effects under `Assets/_Project/Resources/Music/`
and `Assets/_Project/Resources/Sfx/` are all CC0 as well. Their titles, authors and sources are listed in
`Docs/CREDITS.md`. The title splash is an original render made with `Tools/splash/splash.py`.
